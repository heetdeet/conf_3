## Этап 1: Перевод программы в промежуточное представление

### Цель этапа
Создать CLI-приложение ассемблера, реализующее разбор текстового представления команд и трансляцию в промежуточное представление.

### Структура проекта
```
conf_3/
├──src/
|   ├── assembler.py          # Основной код ассемблера
|   ├── example_program.asm # Пример программы на языке ассемблера
|   └── test_program.asm       # Автоматически генерируемый тест из спецификации
└──README.md
```

### Требования к реализации (выполнены)
1. **CLI-интерфейс с тремя аргументами:**
   - Путь к исходному JSON-файлу с программой
   - Путь к двоичному файлу-результату
   - Флаг `--test` для режима тестирования

2. **Язык ассемблера в формате JSON** с поддержкой всех команд спецификации УВМ

3. **Транслятор** преобразующий JSON в промежуточное представление (список словарей)

4. **Режим тестирования**, выводящий внутреннее представление в формате полей и значений

5. **Тестовая программа**, соответствующая примерам из спецификации УВМ

## Спецификация УВМ (вариант №16)

### 1. Загрузка константы
| Поле | Биты    | Описание                    | Диапазон     |
|------|---------|-----------------------------|--------------|
| A    | 0—6     | Код операции = 43           | 43           |
| B    | 7—20    | Константа                   | 0..16383     |
| C    | 21—23   | Адрес регистра-назначения   | 0..7         |

**Размер команды:** 3 байта  
**Формат в ASM:**
```json
# Загрузка констант в регистры
R2 = 100
R3 = 200
R4 = 300

# Чтение из памяти (по адресу в R3) в R5
R5 = [R3]

# Запись значения из R4 в память по адресу (R2 + 50)
[R2 + 50] = R4

# Циклический сдвиг: R6 = R1 сдвинуть на R2
R6 = R1 >> R2

# Еще одна запись в память
[R5 + 100] = R6
```

### 2. Чтение из памяти
| Поле | Биты    | Описание                    | Диапазон     |
|------|---------|-----------------------------|--------------|
| A    | 0—6     | Код операции = 31           | 31           |
| B    | 7—9     | Адрес регистра-источника    | 0..7         |
| C    | 10—12   | Адрес регистра-назначения   | 0..7         |

**Размер команды:** 2 байта  

### 3. Запись в память
| Поле | Биты    | Описание                    | Диапазон     |
|------|---------|-----------------------------|--------------|
| A    | 0—6     | Код операции = 58           | 58           |
| B    | 7—22    | Смещение                    | 0..65535     |
| C    | 23—25   | Адрес базового регистра     | 0..7         |
| D    | 26—28   | Адрес регистра-источника    | 0..7         |

**Размер команды:** 4 байта  


### 4. Циклический сдвиг вправо (ROR)
| Поле | Биты    | Описание                    | Диапазон     |
|------|---------|-----------------------------|--------------|
| A    | 0—6     | Код операции = 24           | 24           |
| B    | 7—9     | Адрес регистра-источника1   | 0..7         |
| C    | 10—12   | Адрес регистра-источника2   | 0..7         |
| D    | 13—15   | Адрес регистра-назначения   | 0..7         |

**Размер команды:** 2 байта

## Использование ассемблера

### Базовый запуск (только этап 1):
```bash

```

### Запуск с тестированием:
```bash
python assembler.py input.asm output.bin --test
```

## Тестирование

Ассемблер автоматически проверяет соответствие тестовым примерам из спецификации:

1. **load_const**: A=43, B=536, C=0 → `0x2B, 0x0C, 0x01`
2. **read_mem**: A=31, B=5, C=1 → `0x9F, 0x06`
3. **write_mem**: A=58, B=402, C=1, D=3 → `0x3A, 0xC9, 0x80, 0x0C`
4. **ror**: A=24, B=1, C=2, D=6 → `0x98, 0xC8`

Все проверки выполняются автоматически при запуске с флагом `--test`.
